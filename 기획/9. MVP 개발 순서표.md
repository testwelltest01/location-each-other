# MVP 개발 순서표

## 1. 목표

실시간 위치추적형 픽업 앱의 MVP를 구현한다.

포함 기능:

- 운전자 세션 생성
- 탑승자 링크 접속
- 탑승자 실시간 위치 공유
- 운전자 지도에서 탑승자 위치 실시간 확인
- 세션 종료 / 링크 만료 처리

---

## 2. 개발 순서

### STEP 1. 프로젝트 기본 세팅

- React Native 프로젝트 생성
- FastAPI 프로젝트 생성
- 환경변수 파일 설정
- PostgreSQL 연결
- Git 초기 세팅

---

### STEP 2. 백엔드 기본 구조 만들기

- DB 모델 생성
  - PickupSession
  - SessionParticipant
  - SessionLink
  - LocationPoint
- FastAPI 라우터 구조 생성
- 기본 API 동작 확인

---

### STEP 3. 세션 생성 기능 구현

- 운전자 세션 생성 API
- 세션 ID 발급
- 링크 토큰 생성
- 세션 생성 응답 반환

---

### STEP 4. 탑승자 링크 접속 기능 구현

- 링크 유효성 검사
- 세션 조회
- 탑승자 세션 참여 처리
- 만료/잘못된 링크 예외 처리

---

### STEP 5. 탑승자 위치 전송 기능 구현

- 위치 권한 요청
- 현재 위치 가져오기
- 위치 API로 서버 전송
- 서버에 위치 저장

---

### STEP 6. 운전자 지도 화면 구현

- 네이버지도 연동
- 운전자 화면에서 세션 조회
- 탑승자 마지막 위치 표시
- 위치 마커 표시

---

### STEP 7. 실시간 위치 반영 구현

- 위치 주기적 전송
- 운전자 화면 주기적 갱신 또는 WebSocket 연결
- 지도에서 탑승자 위치 실시간 업데이트

---

### STEP 8. 세션 종료 / 링크 만료 처리

- 세션 종료 API
- 종료된 세션 접근 차단
- 링크 만료 처리
- 만료 메시지 표시

---

### STEP 9. 테스트

- 2기기 테스트
- 위치 전송 확인
- 지도 반영 확인
- 종료/만료 흐름 확인
- 예외 상황 점검

---

## 3. 추천 구현 우선순위

### 1차

- 세션 생성
- 링크 접속
- 위치 1회 전송
- 지도에 1회 표시

### 2차

- 위치 반복 전송
- 지도 실시간 갱신

### 3차

- 세션 종료
- 링크 만료
- 예외 처리 정리

---

## 4. 핵심 원칙

처음부터 모든 걸 실시간으로 만들지 않는다.  
먼저 아래 흐름이 되는지 확인한다.

세션 생성 → 링크 접속 → 위치 1회 전송 → 운전자 지도 표시

이 흐름이 성공하면 그 다음에 실시간 갱신을 붙인다.
