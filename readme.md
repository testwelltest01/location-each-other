# 실시간 위치추적형 픽업 앱 MVP

## 1. 프로젝트 소개

이 프로젝트는 **운전자가 탑승자의 실시간 위치를 확인하여 픽업을 더 쉽게 할 수 있도록 돕는 앱**의 MVP를 만드는 것을 목표로 한다.

기존 지도 앱의 일반적인 위치 공유 기능은 범용적이지만, 실제 픽업 상황에서는 다음과 같은 문제가 자주 발생한다.

- 탑승자가 자신의 위치를 말로 설명하기 어렵다.
- 운전자는 어디로 가야 할지 바로 판단하기 어렵다.
- 서로 같은 장소를 보고 있다고 생각하지만 실제 위치가 다를 수 있다.
- 실시간으로 위치가 변하면 다시 설명해야 한다.

이 앱은 이런 문제를 해결하기 위해, **짧은 시간 동안만 유효한 픽업 전용 실시간 위치 공유 세션**을 제공한다.

---

## 2. MVP 목표

MVP의 목표는 복잡한 기능을 많이 넣는 것이 아니라,  
**실제 픽업이 가능한 최소 기능만 빠르게 구현하는 것**이다.

즉, 아래 흐름이 동작하면 MVP는 성공이다.

**운전자가 세션을 만든다 → 탑승자가 링크에 접속한다 → 탑승자가 위치를 공유한다 → 운전자가 지도에서 위치를 본다 → 세션이 종료된다**

---

## 3. MVP 포함 기능

이번 MVP에는 아래 기능만 포함한다.

### 1) 운전자 세션 생성

- 운전자가 픽업 세션을 생성한다.
- 서버는 세션 ID와 공유용 링크를 발급한다.

### 2) 탑승자 링크 접속

- 탑승자가 공유받은 링크를 열어 세션에 접속한다.
- 잘못된 링크 또는 만료된 링크는 차단한다.

### 3) 탑승자 실시간 위치 공유

- 탑승자가 위치 권한을 허용한다.
- 탑승자의 위치가 서버로 전송된다.

### 4) 운전자 지도에서 탑승자 위치 실시간 확인

- 운전자는 지도 화면에서 탑승자의 현재 위치를 확인할 수 있다.
- 초기 MVP에서는 마지막 위치 표시가 먼저 되고, 이후 실시간 갱신으로 확장한다.

### 5) 세션 종료 / 링크 만료 처리

- 운전자가 세션을 종료할 수 있다.
- 일정 시간이 지나면 링크와 세션은 만료된다.

---

## 4. MVP 제외 기능

이번 버전에서는 아래 기능을 넣지 않는다.

- 채팅
- 음성 통화
- 푸시 알림 고도화
- 회원 기능 고도화
- 즐겨찾기 장소
- 이동 경로 추천 고도화
- 히스토리/기록 조회
- 다중 탑승자 처리
- 자동 픽업 완료 판단

## 6. 핵심 사용자 흐름

### 운전자

1. 앱에서 픽업 세션 생성
2. 생성된 링크를 탑승자에게 공유
3. 지도 화면에서 탑승자 위치 확인
4. 픽업 완료 후 세션 종료

### 탑승자

1. 공유받은 링크 접속
2. 위치 권한 허용
3. 자신의 위치 공유 시작
4. 픽업 완료 시 세션 종료

---

## 7. 핵심 데이터 구조

MVP에서 중요한 데이터는 아래와 같다.

- `PickupSession`
- `SessionParticipant`
- `SessionLink`
- `LocationPoint`
- `SessionEvent`

즉, 이 앱은 사용자 중심이라기보다  
**세션 중심의 실시간 위치 공유 구조**를 가진다.

---

## 8. 개발 원칙

### 1) 가장 작은 흐름부터 구현

처음부터 모든 실시간 기능을 완성하려고 하지 않는다.

우선 아래가 되는지 먼저 확인한다.

**세션 생성 → 링크 접속 → 위치 1회 전송 → 지도 1회 표시**

그 다음에 위치 반복 갱신을 붙인다.

### 2) 정상 흐름부터 먼저 완성

예외 처리보다 먼저 핵심 성공 흐름을 만든다.

### 3) 상태는 서버 기준으로 관리

세션 상태는 서버가 기준이 되며, 프론트는 이를 표시한다.

### 4) 위치 데이터는 민감 정보로 취급

필요한 범위만 저장하고, 장기 보관은 지양한다.

---

## 10. 성공 기준

MVP는 아래 조건이 만족되면 성공으로 본다.

- 운전자가 세션을 생성할 수 있다.
- 탑승자가 링크에 접속할 수 있다.
- 탑승자가 위치를 공유할 수 있다.
- 운전자가 지도에서 탑승자 위치를 확인할 수 있다.
- 세션이 정상 종료되거나 만료될 수 있다.

## Local Run Guide

### 실행 방법 (개발용)

1. docker-compose 사용(권장)

```bash
docker compose up --build
```

2. health check

```bash
curl http://127.0.0.1:8000/
```

3. 기본 환경변수

- `DATABASE_URL` (권장 기본값): `postgresql+psycopg://postgres:postgres@localhost:5432/pickup_mvp`
- Docker 실행 시: `postgresql+psycopg://postgres:postgres@db:5432/pickup_mvp`

4. 자세한 실행/요청 예시는 `local-run.md` 참조

```bash
[local-run.md](local-run.md)
```

### 최소 테스트 요청

- `POST /api/v1/sessions` : 운전자 세션 생성
- `GET /api/v1/links/{link_token}` : 링크 접속
- `POST /api/v1/links/{link_token}/locations` : 탑승자 위치 공유
- `GET /api/v1/sessions/{session_id}/driver-location` : 운전자 위치 조회
- `POST /api/v1/sessions/{session_id}/end` : 세션 종료
- `GET /api/v1/links/{link_token}/status` : 링크 상태 확인
