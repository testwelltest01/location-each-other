### 1. 핸드폰 준비
1.  핸드폰 기종에 맞는 앱 스토에서 **"Expo Go"** 앱을 다운로드해 주세요.
2.  컴퓨터와 핸드폰이 **같은 Wi-Fi(공유기)**에 연결되어 있는지 확인해 주세요. (가장 중요한 부분입니다!)

### 2. 컴퓨터 설정 (개발 환경 준비)
제가 방금 Expo 실행에 필요한 설정 파일([package.json](cci:7://file:///c:/Users/user/Desktop/20260320/react-native-app/package.json:0:0-0:0), [app.json](cci:7://file:///c:/Users/user/Desktop/20260320/react-native-app/app.json:0:0-0:0))을 업데이트했습니다. 이제 아래 명령어를 순서대로 실행해 주세요.

```powershell
# react-native-app 폴더로 이동 (이동이 안 되어 있다면)
cd react-native-app

# 1. 필요한 패키지 설치 (시간이 조금 걸릴 수 있습니다)
npm install

# 2. Expo 서버 실행
npx expo start
```

### 3. 핸드폰으로 확인하기
1.  위 명령어를 실행하면 터미널에 **커다란 QR 코드**가 나타납니다.
2.  **Android**: "Expo Go" 앱에서 "Scan QR Code"를 눌러 스캔하세요.
3.  **iPhone**: 기본 카메라 앱으로 QR 코드를 스캔한 후 "Open in Expo Go"를 누르세요.

### 학습 팁 💡
*   **Hot Reloading**: 코드를 수정하고 저장(Ctrl + S)하면 핸드폰 화면이 **즉시** 바뀝니다. 제가 아까 달아드린 주석을 보면서 텍스트나 버튼 이름을 바꿔보시면 바로 반영되는 걸 확인할 수 있어요.
*   **네트워크 오류가 난다면?**: 만약 QR 스캔 후 연결이 안 된다면, 터미널에서 `npx expo start --tunnel` 명령어로 실행해 보세요. (네트워크 환경에 구애받지 않고 연결해주는 방식입니다.)
