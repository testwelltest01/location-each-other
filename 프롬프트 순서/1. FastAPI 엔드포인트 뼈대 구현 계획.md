# FastAPI 엔드포인트 뼈대 구현 계획 (codex_readme.md MVP 범위)

## Summary

현재 기능 5개 + 링크 만료 상태 확인 API를 FastAPI로 최소 뼈대 구현한다.  
DB는 연결하지 않고, 스키마/라우터/서비스 시그니처만 두고 TODO/Mock으로 둔다.

## 핵심 변경/구현 항목

1. 프로젝트 최소 구조(신규 생성)

- `app/main.py`
- `app/api/v1/sessions.py`
- `app/api/v1/links.py`
- `app/schemas/session_schemas.py`
- `app/schemas/link_schemas.py`
- `app/services/session_service.py`
- `requirements.txt`(기존이 없으면)
  - `fastapi`
  - `uvicorn[standard]`
  - `pydantic`

2. 라우터 및 엔드포인트

- `app/api/v1/sessions.py` (prefix `/api/v1`)
  - `POST /sessions` → 운전자 세션 생성
    - handler: `create_session(payload: CreateSessionRequest, authorization: Optional[str] = Header(None)) -> CreateSessionResponse`
    - service: `create_session(req: CreateSessionRequest, driver_token: str | None) -> CreateSessionResponse`
  - `GET /sessions/{session_id}/driver-location` → 운전자 위치 조회
    - handler: `get_driver_location(session_id: UUID, authorization: Optional[str] = Header(None), x_link_token: Optional[str] = Header(None)) -> DriverLocationResponse`
    - service: `get_driver_location(session_id: UUID, actor_context: AuthContext) -> DriverLocationResponse`
  - `POST /sessions/{session_id}/end` → 세션 종료
    - handler: `end_session(session_id: UUID, payload: EndSessionRequest, authorization: Optional[str] = Header(None)) -> EndSessionResponse`
    - service: `end_session(session_id: UUID, req: EndSessionRequest, driver_token: str | None) -> EndSessionResponse`

- `app/api/v1/links.py` (prefix `/api/v1`)
  - `GET /links/{link_token}` → 탑승자 링크 접속(유효성 확인)
    - handler: `access_link(link_token: str) -> LinkAccessResponse`
    - service: `get_link_state(link_token: str) -> LinkAccessResponse`
  - `POST /links/{link_token}/locations` → 탑승자 위치 공유
    - handler: `share_passenger_location(link_token: str, payload: ShareLocationRequest, authorization: Optional[str] = Header(None)) -> ShareLocationResponse`
    - service: `share_passenger_location(link_token: str, req: ShareLocationRequest, token: str | None) -> ShareLocationResponse`
  - `GET /links/{link_token}/status` → 링크 만료 상태 확인
    - handler: `get_link_status(link_token: str) -> LinkStatusResponse`
    - service: `check_link_status(link_token: str) -> LinkStatusResponse`

3. Request/Response 스키마

- `app/schemas/session_schemas.py`
  - Request
    - `CreateSessionRequest`
      - `driver_id: UUID`
      - `session_ttl_minutes: int = 120`
      - `link_ttl_minutes: int = 120`
      - `max_access_count: int | None = None`
    - `EndSessionRequest`
      - `reason: str = "driver_end"`
  - Response
    - `CreateSessionResponse`
    - `EndSessionResponse`
    - `DriverLocationResponse`
      - `location: LocationDTO | None`
- `app/schemas/link_schemas.py`
  - Request
    - `ShareLocationRequest`
      - `latitude: float`, `longitude: float`, `accuracy_m: float | None = None`, `recorded_at: datetime | None = None`
  - Response
    - `LinkAccessResponse`
    - `ShareLocationResponse`
    - `LinkStatusResponse`
    - `LocationDTO`(위치 공통 스키마)
      - `latitude`, `longitude`, `accuracy_m`, `recorded_at`

4. 서비스 함수(placeholder)

- `app/services/session_service.py`
  - `create_session(req, driver_token)`
  - `get_link_state(link_token)`
  - `share_passenger_location(link_token, req, token)`
  - `get_driver_location(session_id, actor_context)`
  - `end_session(session_id, req, driver_token)`
  - `check_link_status(link_token)`
  - 모든 함수는 `TODO: DB 연동` 또는 Mock dict/고정 샘플 반환으로 구현하고, 최소 예외만 `HTTPException`으로 처리.

5. 앱 진입점

- `app/main.py`
  - `FastAPI()` 생성
  - `/api/v1` 라우터 include
  - `uvicorn` 실행 가능한 최소 구조 (`if __name__ == "__main__": uvicorn.run(...)` 선택)

## 인증/인가(최소 수준)

- 운전자 API는 `Authorization: Bearer {driver_token}` 헤더를 받되, 현재는 존재 여부만 검증 후 pass.
- 탑승자 위치 업로드/상태 조회는 링크 기반 인증(`link_token`) 우선.
- 상세 권한/토큰 검증/만료 정책은 각 서비스 TODO 주석 처리.

## 에러/예외(간단)

- `400`: 요청 스키마 검증 실패
- `401`: 필수 인증 헤더 누락
- `403`: 상태 불일치(만료/종료된 세션)
- `404`: session/link 미존재
- `410`: 링크/세션 만료

## 테스트/수용 기준(수정 직후 확인)

- `/api/v1/sessions` create 반환에서 `session_id`, `session_token`, `link_token` 존재
- `/api/v1/links/{link_token}` 접속 시 `session_status`, `link_active` 값 반환
- `/api/v1/links/{link_token}/locations` 성공 시 `point_id` 또는 `saved_at` 반환
- `/api/v1/sessions/{session_id}/driver-location` 호출 시 `driver_location` 구조 응답
- `/api/v1/sessions/{session_id}/end` 후 `/api/v1/links/{link_token}/status`에서 접근 불가 플래그가 반영

## 가정(명시)

- 프로젝트 루트에 기존 코드 없음(문서만 존재)으로 빈 FastAPI 프로젝트를 새로 구성.
- 실시간(WebSocket) 없이 polling 기반 조회 API만 우선 반영.
- 좌표 정밀도는 소수점 float 그대로 보관.
- 링크 만료 확인은 상태값 계산 API(`GET /links/{link_token}/status`)로 제공.
